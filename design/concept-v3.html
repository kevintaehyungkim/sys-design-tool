URL shortener

VISUAL CONCEPT Saved locally

Requirements

Fast redirects, durable links, lightweight analytics

FUNCTIONAL

Create immutable short links with POST /links
Redirect using GET /:code
Collect click.created events asynchronously

SCALE & GUARANTEES

10M new links / day · 100:1 reads to writes
p99 redirects < 50 ms
99.99% availability

Design approach

Keep redirects on a cache-first path. Persist each short code once, then process click events asynchronously.

Use Base62 for compact keys and cache-aside reads for durable fallback

Read path & resilience

  • Cache hot links; fall back to the durable store on a miss
  • Enforce unique short_code values and idempotent link creation
  • Queue click.created events so analytics never delays a redirect
